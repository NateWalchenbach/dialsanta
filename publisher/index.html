Dial Santa Paperclip Publisher is the private, owner-operated publishing tool used by Merry in Paperclip to prepare Dial Santa promotional Shorts for the owner's selected YouTube channel.

This website explains the tool and its policies. The application itself runs locally on the owner's computer. There is no public sign-in, paid API service or access for third-party channels.

Current status: private trial. One owner-approved video has been uploaded privately. Public publishing remains gated while the YouTube API audit and the remaining release checks are completed. Google approval is not claimed.

How the owner stays in control

  1. Review the exact video and copy. The owner chooses the media, title, description, privacy, audience classification and AI disclosure.
  2. Authorize a private upload. The client verifies the connected channel and records the operation before sending it to YouTube.
  3. Check the saved result. The client reads back processing and metadata. An uncertain result must be reconciled before retrying.
  4. Approve public release separately. Public release also requires the applicable Google project audit and complete verification. No daily posting schedule is active.

Privacy and review access

Read the publisher privacy policy for the data collected, processors, current retention limits and deletion-request route, and the terms of use before using the client. The publisher supports restricted reporting for registered Dial Santa videos.

Google reviewers can request a recorded demonstration or supervised review using the contact below. Owner credentials and the local administrator interface are not publicly exposed.

The consumer product is Dial Santa for iPhone. This publisher's privacy policy is separate from the consumer app's policy.
